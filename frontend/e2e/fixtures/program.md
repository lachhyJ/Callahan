# Sample Training Program

Synthetic stand-in for the real program document, which lives outside the repo.
It exists so the e2e Program screen renders markdown rather than the
"isn't configured" message.

## Part 1 — Weekly structure

| Day | Session | Focus |
|---|---|---|
| Monday | Gym 1 | Lower body strength |
| Wednesday | Gym 2 | Upper body strength |
| Friday | Gym 3 | Power and accessories |

## Universal gym warm-up

1. Bike, 5 minutes easy
2. Ankle circuit
3. Two ramp-up sets of the first lift

## Part 2 — Progression

Work inside the prescribed rep range. When every working set reaches the top
of the range, add the smallest available weight next session.
